# Buildkite pipelines

This directory contains Buildkite pipeline configuration for CI.

Each `*.rayci.yml` file defines pipeline steps that are parsed by the
[`rayci`](https://github.com/ray-project/rayci) tool and executed according to
the [Buildkite pipeline specification](https://buildkite.com/docs/pipelines).

## Pipelines

CI is configured via `*.rayci.yml` files in this directory, with fork-specific
overrides in `fork-pipeline/`. The pipeline is generated by the `rayci` tool
during the bootstrap step. See `fork-pipeline/` for the active fork configuration.

## Test filtering

The script `ci/pipeline/determine_tests_to_run.py` determines changed files in
a PR and produces tags that control which test groups are triggered. It is
invoked via `ci/ci_tags_from_change.sh`.
